# 프로젝트 전역 스타일 및 디자인 지침

- **폰트 규칙 1**: 사이트 내 기본 폰트는 'SUIT'를 사용하며, 'SUIT' 폰트에는 항상 `letter-spacing: -0.05em` (-5%), `font-weight: 400` (Regular), `line-height: 1.8` (180%)을 기본으로 적용할 것. (관련 토큰: `--line-height-base`, `--font-weight-regular`)
- **폰트 규칙 2**: 보조 폰트로 'Playfair Display'를 사용할 수 있음.
- **버튼 디자인**: 그림자(box-shadow) 절대 금지.
- **헤더**: 스크롤 시 '위로 올릴 때만' 흰색 배경 스티키 헤더 노출.
- **모바일 대응**: 가변 콘텐츠(편지지, 안내 카드 등)가 찌그러지지 않도록 부모 컨테이너에 `width: 100%` 명시.
- **디자인 철학**: 복잡한 장식보다는 간결하고 여백을 살린 세련된 디자인 지향.

- **폰트 규칙 3**: 보조 폰트로 쓰이는 Playfair Display 폰트는 항상 letter-spacing: -0.02em (-2%), line-height: 1.2 (120%)을 적용할 것.
