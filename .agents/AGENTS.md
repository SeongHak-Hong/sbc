# 프로젝트 전역 스타일 및 디자인 지침

- **폰트 규칙 1**: 'LXGWWenKaiMonoKR' 폰트를 사용할 때는 (히어로 섹션을 제외하고) 항상 `line-height: 1.6` 및 `font-weight: 400`을 기본으로 유지할 것.
- **폰트 규칙 2**: 'Pretendard' 폰트를 사용할 때는 항상 `line-height: 1.8`을 기본으로 유지할 것.
- **버튼 디자인**: 그림자(box-shadow) 절대 금지.
- **헤더**: 스크롤 시 '위로 올릴 때만' 흰색 배경 스티키 헤더 노출.
- **모바일 대응**: 가변 콘텐츠(편지지, 안내 카드 등)가 찌그러지지 않도록 부모 컨테이너에 `width: 100%` 명시.
- **디자인 철학**: 복잡한 장식보다는 간결하고 여백을 살린 세련된 디자인 지향.
