# 🌿 SBC 메인 랜딩페이지 기획안 & UI 컴포넌트 명세

> **컨셉:** "문은 늘 열려 있는 교회" — 교회를 *설득하는 곳*이 아니라 *머물러도 되는 곳*으로 그린다.
> **핵심 은유:** **열린 문**(언제든 들어오고 나갈 수 있는 곳)과 **식탁**(함께 먹고 나누는 공동체)
> **디자인 기준:** `design.md`(서브페이지 시스템)의 토큰을 **계승**하고, 메인 페이지 전용 **확장 규칙**(§4)을 추가한다.

### 변경 이력
| 버전 | 내용 |
|---|---|
| v2 | 호흡 가이드(명상 연상) 삭제 → 마음 날씨별 말씀 + 기도 부탁·감사 한 줄로 교체 / 태양·노을 연상 표현 삭제, 핵심 은유를 '열린 문·식탁'으로 변경 / 첫 방문 가이드 '도착해요'에 오시는 길 지도 추가 / 말씀 영상은 빠른 링크로 배치 / 파일 확장자 `.jsx`로 통일, Tailwind 항목 삭제 |

## 0. 문제 정의 → UX 방향

| 구분 | 내용 |
|---|---|
| **문제** | 교회 메인 페이지는 보통 "예배 시간·설교·등록"이 먼저 보여 비신자에게 진입 장벽이 높다. 첫 방문자는 '들어가면 붙잡힐까 봐' 망설인다. |
| **역할 정의** | 메인 페이지는 **새 방문자에게는 위로와 초대**, **기존 성도에게는 빠른 정보 허브**라는 두 역할을 동시에 한다. → 상단은 감정(새 방문자), 하단은 정보(기존 성도)로 흐름을 나눈다. |
| **UX 가설** | 먼저 **위로를 경험**하고(감정), **무엇을 기대할지 정확히 알고**(정보), **언제든 떠날 수 있다고 느낄 때**(통제권) 방문 의사가 생긴다. |
| **서사 흐름** | 공감 → 마음 나누기(말씀·기도) → 가치 → 사람들 → 첫 방문 안심 → FAQ → 초대 → (기존 성도용) 빠른 링크 |
| **핵심 원칙** | ① 요구하지 않는다 ② 모든 CTA는 "보기/알아보기" 수준의 저관여 행동 ③ 개인정보 입력은 끝까지 선택 사항 ④ 영적 경험은 명상이 아닌 **말씀과 기도, 공동체**를 통해 전한다 |

## 2. 섹션별 카피라이팅

### ① Hero — "공감" ✅ 구현 완료

- **아이브로우:** 신탄진침례교회
- **헤드라인:** 오늘 하루, / 많이 애쓰셨죠.
- **서브카피:** 잠시 쉬어가도 괜찮은 곳이 있어요. 아무것도 준비하지 않고, 그냥 오셔도 됩니다.
- **Primary CTA:** `천천히 둘러보기` → 마음 나누기 섹션(`#mind-rest`)으로 스크롤
- **Secondary CTA:** `이번 주 예배 시간 보기`
- **A/B 후보:** "당신의 자리가 여기 있어요." / "잘하지 않아도, 여기선 괜찮아요."

### ② 마음 나누기 (인터랙티브) — "말씀과 기도로 먼저 위로받기"

> 교회 소개보다 먼저, **지금 내 마음에 닿는 말씀 한 구절**과 **나를 위해 기도해 줄 공동체**를 경험하게 하는 장치.

- **섹션 id:** `mind-rest`
- **타이틀:** 지금, 마음 날씨는 어떤가요?
- **선택 버튼:** 흐림 · 비 · 조금 갬 · 맑음 · 잘 모르겠어요 (날씨 아이콘 사용 가능)
- **흐름:** 날씨 선택 → ① 공감 문구 → ② 말씀 한 구절 → ③ 선택 행동(해당 시) → ④ 다음 섹션 연결

#### 날씨별 응답

| 선택 | 공감 문구 | 말씀 (개역개정) | 선택 행동 | 다음 연결 |
|---|---|---|---|---|
| **흐림** | 흐린 날도 하루의 일부예요. 오늘은 조금 천천히 가도 괜찮아요. | 수고하고 무거운 짐 진 자들아 다 내게로 오라 내가 너희를 쉬게 하리라 — 마태복음 11:28 | 기도 부탁하기 | ③ 가치 제안 |
| **비** | 마음에 비가 오는 날이네요. 억지로 괜찮아지지 않아도 돼요. | 여호와는 마음이 상한 자를 가까이 하시고 충심으로 통회하는 자를 구원하시는도다 — 시편 34:18 | 기도 부탁하기 | ③ 가치 제안 |
| **조금 갬** | 조금씩 나아지고 있군요. 그 걸음을 저희도 함께 응원할게요. | 오직 여호와를 앙망하는 자는 새 힘을 얻으리니 독수리가 날개치며 올라감 같을 것이요 달음박질하여도 곤비하지 아니하겠고 걸어가도 피곤하지 아니하리로다 — 이사야 40:31 | 없음 | ④ 활동 소개 (소그룹 탭) |
| **맑음** | 좋은 하루를 보내고 계시네요. 그 마음, 저희도 반가워요. | 항상 기뻐하라 쉬지 말고 기도하라 범사에 감사하라 이것이 그리스도 예수 안에서 너희를 향하신 하나님의 뜻이니라 — 데살로니가전서 5:16-18 | 감사 한 줄 남기기 | ④ 활동 소개 |
| **잘 모르겠어요** | 마음을 다 알지 못해도 괜찮아요. 모르는 채로 와도 되는 곳이에요. | 그리하면 여호와 그가 네 앞에서 가시며 너와 함께 하사 너를 떠나지 아니하시며 버리지 아니하시리니 너는 두려워하지 말라 놀라지 말라 — 신명기 31:8 | 없음 | ⑤ 첫 방문 가이드 |

> ⚠️ 말씀 본문은 게시 전 개역개정 원문과 한 글자씩 대조 확인할 것.

| 연결 대상 | 브릿지 문구 | 버튼 |
|---|---|---|

| ④ 활동 소개 (조금 갬) | 함께 걸어갈 사람들이 있어요. | `작은 모임 보기` |
| ④ 활동 소개 (맑음) | 기쁨은 나눌수록 커져요. 함께 밥 먹을 식탁이 있어요. | `모임 둘러보기` |
| ⑤ 첫 방문 가이드 | 처음 오시는 날이 어떤지 먼저 보여드릴게요. | `첫 방문 안내 보기` |

#### 선택 행동 — 기도 부탁하기 (흐림·비)

- **버튼:** `기도를 부탁해도 될까요`
- **입력(Drawer):** "어떤 마음인지 적어주셔도 좋고, 비워두셔도 괜찮아요." (최대 300자, 비워도 제출 가능)
- **안내:** 이름 없이 남겨져요. 교회가 이번 주에 함께 기도할게요.
- **완료:** 마음을 맡겨주셔서 고마워요. 함께 기도할게요.

#### 선택 행동 — 감사 한 줄 남기기 (맑음)

- **버튼:** `오늘의 감사 한 줄 남기기`
- **입력(인라인):** "오늘 감사한 일을 한 줄로 적어주세요." (최대 100자)
- **안내:** 이름 없이 남겨져요.
- **완료:** 나눠주셔서 고마워요. 그 감사, 저희도 함께 기뻐할게요.

#### 데이터 원칙

- 날씨 선택값 자체는 **저장하지 않는다** (로컬 상태만).
- 기도 부탁·감사 한 줄은 사용자가 **제출 버튼을 누른 경우에만** 익명 저장.
- 저장 필드는 최소화: `type`(prayer | gratitude), `weather`, `text`, `createdAt`. 이름·연락처·기기 정보 저장 금지.
- Firestore 규칙은 **쓰기만 허용, 읽기는 관리자만**. 스팸 대응(App Check 또는 제출 간격 제한) 적용.
- 운영 전 확인: 기도 부탁을 누가 확인하고, 어떤 주기로 함께 기도할지 교회 내 담당자와 방식 확정.

| 안정감 | 흔들리는 날에도 기댈 자리 | 매주 같은 자리, 같은 시간. 반복되는 작은 쉼이 마음의 뿌리가 되어줘요. |

| 환대 | 처음이어도 어색하지 않게 | 믿음이 있든 없든, 질문이 많든 적든. 있는 그대로 환영해요. |

### ④ 교회 활동 소개 — "이렇게 모여요" (id: `activities`)

- **타이틀:** 작은 모임, 따뜻한 식탁
- **서브:** 거창한 것보다, 함께 밥 먹고 이야기 나누는 게 먼저예요.
- **Switch Tabs:** `소그룹` · `문화행사` · `다음세대` (마음 나누기에서 '조금 갬'으로 넘어오면 `소그룹` 탭이 선택된 상태로 표시)

| 탭 | 항목 | 카피 | 메타 |
|---|---|---|---|
| 소그룹 | 작은 식탁 (구역 모임) | 6~8명이 둘러앉아 한 주의 이야기를 나눠요. 듣기만 해도 괜찮아요. | 매주 · 동네별 |
| 소그룹 | 책과 차 | 한 달에 한 권, 에세이부터 교양서까지 함께 읽어요. | 월 1회 · 비신자 환영 |
| 문화행사 | 계절 피크닉 | 봄엔 꽃길, 가을엔 금강 산책로. 계절마다 소풍을 가요. | 분기 1회 · 가족 환영 |
| 문화행사 | 떡볶이데이 | 부담 없이 들러 떡볶이 한 접시 나누는 날이에요. | 기존 행사 연계 |
| 다음세대 | 교회학교 | 예배 시간 동안 아이들은 선생님들과 안전하게 지내요. | 영유아~청소년 |

> 💡 다음세대 페이지의 `교회학교 / 떡볶이데이` 스위치 카드 패턴을 재사용하면 일관성이 생겨요.

### ⑤ 첫 방문 가이드 — "부담 완화" (id: `first-visit`)

- **타이틀:** 처음 오시는 날, 이렇게 흘러가요
- **상단 배지:** 등록하지 않으셔도 됩니다

| 단계 | 타이틀 | 설명 |
|---|---|---|
| 01 | 도착해요 | 주차장은 건물 뒤편에 있어요. 입구에서 안내 봉사자가 반갑게 맞아드려요. **+ 오시는 길 지도(주소 복사, 지도 앱 열기 버튼)** |
| 02 | 편한 자리에 앉아요 | 뒷자리, 구석 자리 모두 괜찮아요. 순서를 몰라도 따라오지 않으셔도 돼요. |
| 03 | 차 한 잔 할래요? | 예배 후 카페에서 따뜻한 차를 드려요. 바로 가셔도 전혀 실례가 아니에요. |
| 04 | 다음은, 원하실 때 | 연락처를 남기지 않아도 돼요. 또 오고 싶을 때 그냥 오세요. |

- **보조 카피:** 헌금은 참여하지 않으셔도 괜찮아요. 복장도 평소처럼 편하게 오세요.
- **선택형 CTA:** `혼자 오기 어색하다면, 동행을 요청하세요` → 이름(닉네임 가능) + 연락 수단 1개만 받는 간단한 폼 (Drawer)

- **서브:** 오늘이 아니어도 괜찮아요. 마음이 닿는 날, 기다리고 있을게요.
- **CTA:** `오시는 길 보기` · `예배 시간 확인하기`

### ⑧ 빠른 링크 (기존 성도용)

- 카드 4개: `예배 안내` · `설교·말씀 영상` · `소식·주보` · `오시는 길` → 각 서브페이지로 연결
- 말씀 쇼츠 영상은 새 방문자 흐름에 넣지 않고, `설교·말씀 영상` 링크로 연결

## 5. 프론트엔드 고려사항

### 컴포넌트 구조 (기존 프로젝트 재사용 우선)

```
src/
├─ pages/Home/
│  ├─ HomePage.jsx                 # 섹션 조립만 담당
│  └─ sections/
│     ├─ HeroSection.jsx           ✅ 완료
│     ├─ MindRestSection.jsx       # 마음 나누기
│     ├─ ValueSection.jsx
│     ├─ ActivitySection.jsx
│     ├─ FirstVisitSection.jsx
│     ├─ FaqSection.jsx
│     ├─ ClosingSection.jsx
│     └─ QuickLinkSection.jsx
├─ components/
│  ├─ (재사용) Header, Card, SelectButton, SwitchTabs, ScrollFadeText, Drawer
│  └─ (신규)   MoodPicker, VerseCard, AnonymousNoteForm, StepTimeline,
│              Accordion, MobileBottomBar, CompanionForm
├─ content/home.js                 # 모든 카피·말씀·FAQ·활동 데이터 분리
├─ lib/notes.js                    # 기도 부탁·감사 한 줄 Firestore 저장
└─ hooks/ useScrollPast.js
```

**설계 포인트**
- 카피·말씀 본문은 `content/home.js`로 분리 → 담당자가 코드 수정 없이 문구·구절 교체
- 날씨 선택값은 로컬 상태만 사용, 서버 전송 없음
- `AnonymousNoteForm`은 `type: 'prayer' | 'gratitude'` prop 하나로 기도 부탁·감사 한 줄을 모두 처리
- 기도 부탁 입력은 `Drawer` 재사용 (모바일 풀스크린 자동 대응), 감사 한 줄은 카드 안 인라인 입력
- 다음 섹션 연결 시 활동 섹션의 탭 선택값을 함께 전달 (예: `?tab=smallgroup` 대신 상위 상태 또는 이벤트로 전달)
- 모션 감소 대응은 framer-motion `useReducedMotion` 사용

### 스타일링 — CSS Modules + 기존 토큰

- 전역 토큰은 `src/index.css`의 `:root`, 컴포넌트 스타일은 `*.module.css`
- Tailwind 사용하지 않음. 색상·크기는 하드코딩하지 말고 토큰 사용.
- 메인 전용 추가 토큰:

```css
:root {
  --color-accent-sky: #37ABEA;      /* 다음세대 페이지 시계 숫자 색과 동일 */
}
```

- Hero 스타일은 구현된 `HeroSection.module.css`를 기준으로 삼는다.

### 모션 원칙

| 요소 | 효과 | 비고 |
|---|---|---|
| Hero 헤드라인 | 단어 단위 blur(10px)→0, opacity 0.1→1, stagger 0.08s, duration 0.8s | 페이지 로드 시 재생 |
| 섹션 타이틀 | ScrollFadeText (동일 스펙) | `once: true` |
| 카드·버튼 hover | `translateY(-2px)` 0.2s ease | 전역 통일 |
| 마음 나누기 응답 교체 | opacity + translateY(8px) 0.4s | 과한 연출 금지 |
| 하단 바 | opacity + translateY 0.3s | Hero 통과 시 |
| 공통 이징 | `cubic-bezier(0.16, 1, 0.3, 1)` | |

### 접근성 체크
- 본문은 Slate 600 이상 사용 (Slate 400은 메타 정보에만)
- MoodPicker 버튼에 `aria-pressed`, 응답 영역에 `aria-live="polite"`
- 입력창에는 보이는 label 또는 `aria-label` 필수, 글자 수 제한 안내
- Accordion은 `button` + `aria-expanded` + `aria-controls`
- Hero 헤드라인은 `h1` 하나만, 이후 섹션은 `h2`
